## 3. How to Execute the Demo Locally

1. Clone or download the repository.
2. Open Android Studio.
3. Select **File > Open** and browse to the code/ folder of this project.
4. Allow Gradle to synchronize dependencies.
5. Connect an Android physical device or start an Android Virtual Device (AVD, API 26+).
6. Click **Run > Run 'app'** (Shift + F10) to launch the application.
